---
name: Don't repeat content across notes
description: Link to other notes instead of duplicating their content
type: feedback
---

Never copy or repeat content from one note into another. Instead, link to the source note using wikilinks.

**Why:** Duplication breaks the garden's interconnected structure and creates maintenance burden. The value of a digital garden is in its networked relationships, not in having all information available everywhere.

**How to apply:** When tempted to include content from another note, use `[[Note Name]]` to link to it instead. Let readers follow the link to get the full context. Keep each note focused and unique in perspective.
